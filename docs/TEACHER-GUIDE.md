# Teacher Guide

## Daily workflow

A typical teacher workflow in UWEBBZ LMS 5 is:

1. Open the V5 Dashboard.
2. Create or select a course.
3. Build the curriculum manually, with AI Course Architect, or from a Teaching Library.
4. Add or edit lessons.
5. Assign students to the course.
6. Control lesson availability and release timing.
7. Add quizzes or assignments as those engines are completed.
8. Monitor progress and reports.
9. Communicate through announcements and notifications.

## Create a course manually

Open **V5 Course Builder**. Select an existing course or create a new one. Add modules, then add lessons inside each module.

## Create a course with AI

Open **AI Course Architect**, paste source material, choose the audience level, generate a blueprint, review it, then build it into a new or existing course.

## Create a course from Google Drive

First approve the source folder in **Teaching Libraries**. Then open **Build from Teaching Library**, select the approved library, scan it, review the detected modules/resources, choose a course, and build the structure.

## Create one lesson with AI

Open **AI Lesson Builder**, paste teaching content, choose the audience and depth, select the destination course, and generate the lesson. Review before publication.

## Enrollment

Use the visual enrollment workspace to choose a student and course. The enrollment is stored in user metadata and the integrated notification layer can send a course enrollment email.

## Content release

Lessons may use availability metadata for immediate, scheduled, or hidden release depending on the component used to create them. Always verify the student view before launching a course.

## Recommended pre-launch test

Create a test student account, enroll it in the course, open the student portal as that account, verify only intended resources are visible, test scheduled content, and confirm enrollment email delivery.
