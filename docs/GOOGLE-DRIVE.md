# Google Drive Setup

## Google Cloud

1. Create or select a Google Cloud project.
2. Enable the **Google Drive API**.
3. Configure the OAuth consent screen.
4. Create an OAuth 2.0 **Web application** client.
5. Copy the exact redirect URI shown by UWEBBZ LMS into Google Cloud as an Authorized Redirect URI.
6. Enter the Client ID and Client Secret in UWEBBZ LMS Google Drive settings.
7. Connect the Google account.

The redirect URI normally follows this pattern:

`https://YOUR-SITE/wp-admin/admin.php?page=uld`

Always use the exact value generated by the plugin.

## All My Drive

**All My Drive** is the teacher's private browsing area. It can show the connected Drive hierarchy so the teacher can locate folders and resources.

The purpose of this area is discovery and administration, not broad student assignment.

## Teaching Libraries

Teaching Libraries are approved Drive folders that form the assignment boundary for UWEBBZ LMS.

A teacher can add a Teaching Library by:

- Browsing All My Drive and clicking **Add to Teaching Libraries** on a folder, or
- Pasting a specific Drive folder URL or folder ID into Teaching Libraries.

Approved libraries can then be assigned to students or courses and can be used by **Build Course from Teaching Library**.

## Recommended Drive organization

A clean course library can use a structure such as:

- Course Folder
  - Module 1
    - Lesson 1 PDF
    - Lesson 2 Slides
    - Lesson 3 Doc
  - Module 2
    - Lesson 4 PDF
    - Lesson 5 Video
  - Course Resources

The V5 importer currently treats top-level subfolders as modules and files inside them as lesson resources.

## Permissions

Read-only access is sufficient for browsing. Features that create or modify Drive content require a write-capable Drive permission such as the app-specific file scope supported by the plugin configuration.

If Drive browsing works but creation/sync fails, reconnect Google with the required permission and retest.

## Security

Do not commit Client Secrets, access tokens, or refresh tokens to GitHub. These values belong in WordPress/server configuration only.
