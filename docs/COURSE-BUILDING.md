# Course Building

UWEBBZ LMS 5 supports three primary course-creation paths.

## 1. Visual Course Builder

Use when the teacher already knows the curriculum structure.

Workflow:

1. Select a course.
2. Add modules.
3. Add lessons within each module.
4. Open lessons for editing.
5. Continue adding resources, assessments, and release rules.

## 2. AI Course Architect

Use when the teacher has source material but wants help designing the curriculum.

Workflow:

1. Paste source material.
2. Choose audience level.
3. Generate blueprint.
4. Review modules and lessons.
5. Choose a new or existing course.
6. Build the approved structure.

The current AI blueprint creates draft lessons so the instructor can review them before publication.

## 3. Build from Teaching Library

Use when course materials are already organized in Google Drive.

Current import mapping:

- Approved library = course content source
- Top-level folder = module
- Files inside folder = lesson resources
- Root-level files = Course Resources module

The importer shows a preview before creating WordPress content.

## Recommended curriculum structure

A strong course typically includes:

- Course overview
- Learning outcomes
- Sequential modules
- Lessons with measurable objectives
- Practice activities
- Knowledge checks
- Assignments
- Summative assessment
- Completion criteria
- Certificate where appropriate

## Data relationships

Course relationships are primarily stored with WordPress post metadata such as course ID, module ID, ordering, Drive IDs, and availability settings.
